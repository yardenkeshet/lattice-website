# UX Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Four targeted UX fixes: (1) entire Lattice Tile section opens TileMenu on click, (2) inner-radius validation with a generic error system, (3) per-panel clear button inside the 3D viewer, (4) remove Navbar and add home-page CTA.

**Architecture:** All changes are in the React frontend (`react_frontend/`). A new `ValidationError` type in `api/types.ts` is the shared contract for Fix 2. Fixes 1, 2, 3 are component-level; Fixes 3 and 4 also touch `ToolPage` and `HomePage` for wiring and page layout.

**Tech Stack:** React 18, TypeScript, Vite, Radix UI, React Three Fiber, Storybook 7, react-router-dom v6.
